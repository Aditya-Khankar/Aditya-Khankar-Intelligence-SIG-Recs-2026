# Fourier-Operator-Field-Unmixing

This tests if Fourier neural operators can figure out how to unmix complex 3D fields completely on their own, and still handle larger outputs.

Because phase shifts $e^{i \theta}$ rotate values in the complex plane while the regular real valued activations squash them, the model is forced to keep track of wave phase while taking care of non linear changes in wave strength.

## Task overview

You're given continuous 3D fields recorded over time across 2 channels, $S \in \mathbb{R}^{B \times 2 \times 16 \times 16 \times 16}$. Each signal is made by mixing two hidden fields using a non linear formula:

- **X̂ (Low frequency macro drift):** Smooth and continuous background field operating across the entire domain (A background signal that changes slowly).
- **Ŷ (High frequency wave burst):** A fast and localized wave signal with quick phase changes.

The observed signal S is generated by:

$$S = \text{Re}\left(\hat{X} \cdot e^{i \cdot \text{Im}(\hat{Y})}\right) + \tanh(\text{Re}(\hat{X})) \odot \sigma(\text{Re}(\hat{Y}))$$

Your goal is to build **2** separate Fourier Neural Operators (FNOs) that work together to unmix S back into its complex field components **X̂, Ŷ ∈ C^(B × 2 × 16 × 16 × 16)** without using any ground truth target labels (X, Y).




## Task instructions


1) Build two separate FNO models:
   - FNO 1 (Low Freq Model): this one captures slow background drift using low pass fourier mode cutoffs (**M_t, M_x, M_y = 2, 4, 4**).
   - FNO 2 (High Freq Model): this captures fast wave bursts using higher fourier mode cutoffs (**M_t, M_x, M_y = 6, 6, 6**).
   - Constraint: Both models must be strictly independent classes. Don't share any layers, backbones, or encoders between them.

2) - Both models must take input signal $S \in \mathbb{R}^{B \times 2 \times 16 \times 16 \times 16}$.
   - Both models must output complex tensors (**X̂, Ŷ ∈ $\mathbb{C}^{B \times 2 \times 16 \times 16 \times 16}$**) using torch.complex64 precision and 3D FFTs.

3) - Rebuild the input signal **S** by combining your predicted fields **X** and **Y** using the mixing equation.

   - **IMPORTANT**: You **MUST** ensure that both FNOs contribute actively.
   - **Any solution where one FNO learns the entire signal while the other outputs near zero or trivial noise isn't accepted.**
   - **You are free to design loss constraints or regularizations to do so**.

4) - Don't hardcode fixed grid sizes (like **16**) inside your code. Models trained on **16 x 16 x 16** grids will be tested on **64 x 64 x 64** grids.

Also signal values fade to 0 along the spatial edges.


## Dataset https://huggingface.co/datasets/rohithp-alt2/fno-3D-source-unmixing


## Submission

FNO 1 and FNO 2: Ur models, their architecture, saved weights that can split S back into two complex signals (X̂, Ŷ) and work on larger 64 × 64 × 64 grids. Also submit any kind of a mathematical proof for the custom loss/regularization terms that you used to constrain FNO 2 to high frequencies and prevent one model from absorbing the entire signal.
